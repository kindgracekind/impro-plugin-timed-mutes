# Timed Mutes

Mute an account for a set amount of time instead of forever.

- Open any profile or post context menu and pick **Mute for a while…** to choose a duration.
- The account is muted immediately and unmuted automatically once the timer runs out (the plugin checks while the app is open, and catches up on any expired mutes the next time it loads).
- Manage active timed mutes — extend them or unmute early — from the plugin's settings page.

Timed mutes are stored in your account's private plugin settings, so they sync across your devices.

**Note:** If you disable or uninstall the plugin while a timed mute is still active, that account will stay muted until you unmute it manually.
